## Selected work

**Ghuri, a trip-planning app for Bangladesh**
A tourism app that helps people discover destinations, estimate travel costs and plan trips around a budget. I built it with a team of six during my time at DevCave. My part was 10+ screens in React Native, API integration, Firebase authentication, and bug fixing. The app is working and was being prepared for a Google Play release.
Stack: React Native, Expo, TypeScript, Firebase, Node.js

**Bakir Khata, credit management for local shops**
A two-sided app for shopkeepers and customers to keep track of credit (baki) digitally, designed around how small shops in Bangladesh actually operate.
Stack: React Native, Firebase

**Scroll-driven 3D hero section**
A web experiment recreating a scroll-based 3D effect, built to learn how WebGL, shaders and smooth scrolling work together.
Stack: Three.js, GSAP ScrollTrigger, Lenis, GLSL
